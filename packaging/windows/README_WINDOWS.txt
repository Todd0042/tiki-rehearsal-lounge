🌺 TIKI REHEARSAL LOUNGE — WINDOWS PRACTICE STUDIO (v1.0.0) 🍹
========================================================================

Welcome to Tiki Rehearsal Lounge!
Turnkey Vocal Range Calibration, Pitch Sweeps & Smart Key Rehearsal Studio.

QUICK START:
------------
1. Launch TikiRehearsalLounge.exe.
2. The Studio Cockpit Window will load on your screen.
3. If you also have Tiki Karaoke installed, it will automatically connect
   to your shared karaoke.db library and tracks!
4. Calibrate your vocal range via Exercise 1 (Siren Glide) & Exercise 2 (Anchor Note).
5. Select any song and receive instant Smart Key transposition recommendations (-3 to +3).

FILES & DIRECTORIES:
--------------------
- User Settings & Profiles:
  %LOCALAPPDATA%\TikiRehearsalLounge\vocal_profile.json
- Performance Rehearsal Takes:
  %TEMP%\tiki_rehearsal_takes\
- Shared Karaoke Library:
  %USERPROFILE%\Music\Karaoke\Tiki (or integrated from Tiki Karaoke)

SYSTEM REQUIREMENTS:
--------------------
- Windows 10 or Windows 11 (64-bit)
- Standard USB Microphone or audio interface
- Headphones recommended for vocal rehearsal and pitch monitoring
